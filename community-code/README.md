# Community scripts and projects

Tools shared in the [Community Development thread](https://discord.com/channels/313453805150928906/945580784629215253). Browser userscripts generally require a userscript manager such as Tampermonkey or Violentmonkey.

## Replay and analysis tools

### AWBW Replay Player

A desktop player for AWBW replays. [Latest release](https://github.com/DeamonHunter/AWBW-Replay-Player/releases/latest) · [Previous releases](https://github.com/DeamonHunter/AWBW-Replay-Player/releases).

### Replay parser

Tools for parsing AWBW replays. [Open Replay parser](<https://github.com/TarkanAl-Kazily/awbw_replay_parser>).

### AWBW Stats

Enhanced statistics for AWBW games. [Open AWBW Stats](<https://github.com/zielinskigr/awbw_stats>).

### ELO history plotter

Plots a player’s rating history; configure the username and scraping options in the script. [Open ELO history plotter](<authors/ekkehard8/files/AWBW_ELO_history_plotter__2026-03-15.py>).

### AWBW Map Analyzer

Analyzes AWBW maps. [Open AWBW Map Analyzer](<https://greasyfork.org/en/scripts/524216-awbw-map-analyzer-v5-3>).

## Browser tools

### AWBW Enhancements

Browser extension with improvements for AWBW, including move planner tools. [Open AWBW Enhancements](<https://github.com/kbuzsaki/awbw_enhancements>).

### Advanced Hotkeys

Adds keyboard controls for AWBW. [Open Advanced Hotkeys](<https://greasyfork.org/en/scripts/557553-awbw-advanced-hotkeys>).

### Gamepad Controls

Play AWBW with a gamepad. The archived copy is version 0.9.3. [Open Gamepad Controls](<authors/truniht/files/awbw_gamepad.js>).

### Game notes

Add notes to matches and replays. Archived version 1.04. [Previous version](authors/truniht/files/AWBW_game_notes-1.03.user.js). [Open Game notes](<authors/truniht/files/AWBW_game_notes-1.04.user.js>).

### Capture limit

Calculates and displays the capture limit on player panels. [Open Capture limit](<https://greasyfork.org/en/scripts/511814-awbw-capture-limit>).

### Capture display (Pure Version)

Shows balanced property counts, communications towers, units, and days. [Open Capture display (Pure Version)](<https://greasyfork.org/zh-CN/scripts/577857-awbw-%E5%8D%A0%E9%A2%86%E6%98%BE%E7%A4%BA-pure-version-3-0520-stable>).

### Change army direction

Use the arrow in the army selector to change a player’s facing direction. [Archived version 1.02](authors/truniht/files/AWBW_Change_army_direction-1.02.user.js) · [Previous version](authors/truniht/files/AWBW_Change_army_direction-1.01.user.js). [Open Change army direction](<https://greasyfork.org/en/scripts/517608-awbw-change-army-direction>).

### Disable useless units

Disables selected units in the build menu. Archived version 0.2. [Previous version](authors/steve3440/files/disable-units.js). [Open Disable useless units](<authors/rainfallpianist/files/awbw-disable-useless-units-0.2.user.js>).

### Undo Buy

Click units to undo purchases before ending the turn. [Open Undo Buy](<authors/steve3440/files/undo-buy.js>).

### Improved Build Menu

Keeps the build menu on screen and uses two columns when needed. [Open Improved Build Menu](<authors/steve3440/files/build-menu.js>).

### Map Editor Enhancements

Adds configurable keybindings and other map editor improvements. [Open Map Editor Enhancements](<authors/steve3440/files/mapeditor.js>).

### Swap Sides

Adds a move planner button to swap sides on two-player rotationally symmetric maps. [Open Swap Sides](<authors/steve3440/files/swapCountries.js>).

### Acid Rain Brighter Sprites

Makes Acid Rain units easier to distinguish. [Open Acid Rain Brighter Sprites](<authors/vincent-binsento/files/AWBW_Acid_Rain_Brighter_Sprites.user.js>).

### Power Charge Restyling

Removes power bar animation, adds dynamic colors, and fixes spacing. [Current release](https://greasyfork.org/en/scripts/496687-awbw-power-charge-restyling). Archived version 1.0: [Open Power Charge Restyling](<authors/vincent-binsento/files/AWBW_Power_Charge_Restyling-1.0.user.js>).

### Timer warning sounds

Adds sound warnings for the AWBW timer. [Open Timer warning sounds](<https://greasyfork.org/en/scripts/480914-awbw-timer-warning-sounds>).

### Improved AWBW Music Player

Adds music playback to AWBW. [Open Improved AWBW Music Player](<https://greasyfork.org/en/scripts/518170-improved-awbw-music-player>).
