## Method

- Source: the exported "Community Development" thread; every message was captured with a resumable crawl that reached the start of the thread.
- Message classification and link extraction are generated from the Discord export; artifacts are copied only when they were downloaded under the script/text filter.
- Media and archives were never downloaded. Non-script attachments were skipped.
- Files larger than the size limit are excluded and linked through their source message instead.
- Exact duplicate files from the same author are collapsed by SHA-256.
- Fenced code blocks are saved as snippets. Untagged blocks are saved as `.txt` and should be reviewed before use.
- Inline code is counted but not exported because it is mostly short commands and field references; it remains available through the source messages.
- Filenames are sanitized. When a name repeats, the date and message ID are added so versions do not overwrite each other.
