# Community scripts and projects

*Documentation last updated: 2026-10-29*

Tools shared by the AWBW community. Userscripts generally require a userscript manager such as Tampermonkey or Violentmonkey. Published projects link to their hosting sites; Discord-shared files are copies kept in this repository. Some published projects also have archived versions. Entries are sorted by last updated date, newest first; entries without a known date come last. The [source index](sources.csv) records archived files and their sources; browse the [author directories](authors/) for more files and snippets.

## Featured

### AWBW Enhancements

![github.com](https://img.shields.io/badge/github.com-24292f?style=flat) · **Last updated:** 2026-10-20

A browser extension by **saltor (kbuzsaki)** with Moveplanner Plus, damage calculator integration, and replay shortcuts.

[Original extension](https://github.com/kbuzsaki/awbw_enhancements)

**darthnoob (carsonhu)** adds move planner hotkeys, tree-based snapshots, weather controls, automatic repairs, Hachi cost modifiers, and Firefox support. Install the fork as an unpacked extension.

[darthnoob’s fork](https://github.com/carsonhu/awbw_enhancements)

**elio (e-lio)** builds on darthnoob’s fork and adds movement tracers and other planning improvements. The author describes its additions as lightly tested.

[elio’s fork](https://github.com/e-lio/awbw_enhancements)

**Move Planner fix**, by soccer152, fixes the unit values and power bar displayed by AWBW Enhancements in the move planner.

[Open script](https://greasyfork.org/en/scripts/591411)

### AWBW Music Player

![greasyfork.org](https://img.shields.io/badge/greasyfork.org-670000?style=flat) · **Last updated:** 2026-05-07

DeveloperJose’s improved version of twiggy_’s music player recreates the original game audio experience with extra sound effects, music, and customization.

**Author:** DeveloperJose

[Improved Music Player](https://greasyfork.org/en/scripts/518170-improved-awbw-music-player) · [Original Music Player by twiggy_](https://greasyfork.org/en/scripts/459630-awbw-music-player)
