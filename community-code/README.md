# Community scripts and projects

Tools shared in the [Community Development thread](https://discord.com/channels/313453805150928906/945580784629215253). Browser userscripts generally require a userscript manager such as Tampermonkey or Violentmonkey. Dates indicate when a link or archived file was shared in the thread.

## AWBW Enhancements

### Original extension

Browser extension by **saltor (kbuzsaki)** with Moveplanner Plus, damage calculator integration, and replay shortcuts.

[Project](https://github.com/kbuzsaki/awbw_enhancements) · Shared 2022-12-19

### darthnoob’s fork

**darthnoob (carsonhu)** adds move planner hotkeys, tree-based snapshots, weather controls, automatic repairs, Hachi cost modifiers, and Firefox support. Install it as an unpacked extension.

[Project](https://github.com/carsonhu/awbw_enhancements) · Shared 2025-11-22

### elio’s fork

**elio (e-lio)** builds on darthnoob’s fork and adds movement tracers and other planning improvements. The author describes its additions as lightly tested.

[Project](https://github.com/e-lio/awbw_enhancements) · Shared 2026-06-19

[Earlier extension](https://github.com/kbuzsaki/awbw_enhancements) · [darthnoob’s fork](https://github.com/carsonhu/awbw_enhancements)

## Replay and match analysis

### AWBW Replay Player

Downloads and plays completed AWBW replays on your computer. It saves replays locally, highlights actions with custom animations, and lets you change player countries and unit facing directions.

**Author:** DeamonHunter

**Shared:** 2023-04-02

[Latest release](<https://github.com/DeamonHunter/AWBW-Replay-Player/releases/latest>) · [Previous releases](<https://github.com/DeamonHunter/AWBW-Replay-Player/releases>)

### Replay parser

A Python package for opening replay archives and stepping through actions and game states. Use it to analyze players, units, buildings, and funds; the project also provides an interactive Colab notebook.

**Author:** Tarkan Al-Kazily

**Shared:** 2025-06-06

[Open Replay parser](<https://github.com/TarkanAl-Kazily/awbw_replay_parser>)

### AWBW Stats

Adds a Stats button and graphs for two-player games. The author recommends completed games or ongoing standard and high funds games. Available as a browser extension or userscript.

**Author:** zielinskigr

**Shared:** 2022-09-18

[Open AWBW Stats](<https://github.com/zielinskigr/awbw_stats>)

### ELO history plotter

Scrapes and plots a player’s rating history. The latest archived script can include an alternate account and find rivals; set the username and enable scraping on the first run.

**Author:** Ekkehard8

**Shared:** 2026-03-15

[Open ELO history plotter](<authors/ekkehard8/files/AWBW_ELO_history_plotter__2026-03-15.py>)
