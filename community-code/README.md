# Community scripts and projects

Tools shared by the AWBW community. Userscripts generally require a userscript manager such as Tampermonkey or Violentmonkey. Entries with available Greasy Fork install counts appear first, ordered by total installs; other entries follow by newest known date. Install counts are a snapshot.
